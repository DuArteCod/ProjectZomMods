# Verdinha Mod

## Instalação e testes

1. Copie a pasta Verdinha para Zomboid/mods/.
2. Ative o mod no Launcher no servidor e em todos os clientes (obrigatório para multiplayer).
3. Testes:
   - A caixa (100 da Braba) tem opção 'Abrir caixa' que gera 10 maços (10 da Verde).
   - No maço: 'Pegar Verdinha' cria 1 unidade Verdinha no inventário; também é possível fumar direto do maço.
   - Fumar exige isqueiro/matches como o cigarro padrão.
   - Efeitos ao fumar:
       - HungerChange = -50
       - ThirstChange = -50
       - UnhappyChange = -20
       - BoredomChange = -50
       - StressChange = -15

4. Logs: verifique Zomboid/debug.log para mensagens "Verdinha: mod carregado" e "Verdinha: distribuições modificadas".
